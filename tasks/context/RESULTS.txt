# Results

The 2026-09-20 science supplement (eighteen tasks, [science tasks](SCIENCE_TASKS.md)) and the 115 tasks unblocked later that day (section 8) are included in the counts below. A separate science expansion (biology, materials, Earth, physics, economics; [roadmap](SCIENTIFIC_DATASET_EXPANSION.md)) was still being added when these numbers were taken and keeps its own evidence files (`validation/science-expansion-report.json`).

All numbers were measured on this repository on 2026-09-20 (macOS 15 on Apple silicon, Python 3.12, SCiEL commit `da80706f`, Docker through colima). Raw evidence is in `validation/` and, for model runs, in the git-ignored `runs/` directory.

## 1. Suite execution test (every task)

Counts in this section are for the 903 tasks after duplicate merging, the science supplement and the recreations of section 8 (`docs/TASKS.md`, section 1b); the execution report was pruned to them, which loses nothing because every removed task shared its evaluator with a kept one.

`scripts/test_suite.py` ran every `suite/<id>/evaluator.py` on its own seed program in a fresh interpreter with the task's timeout, the OpenRouter key exported, run-time downloads allowed and five-item samples for model-driven tasks ([full table](SUITE_REPORT.md), [JSON](../validation/suite-report.json)).

| Outcome | Tasks |
|---|---:|
| evaluator ran and scored the seed | **625** |
| runnable but a local requirement is missing | 3 |
| evaluator ran and rejected its seed | 4 |
| crashed or timed out | 0 |
| documented unsupported (stub confirms it) | 270 |

By protocol: original 124 of 130 ran, recreated_verified 81 of 81, recreated 420 of 422. The three requirement-blocked tasks are the GPQA benchmark (one task after merging; the dataset is gated on Hugging Face and needs `HF_TOKEN`), the Kattis online-judge example (needs an account) and the lm-eval example (a command-line driver with no `evaluate()`). The four seed rejections are one ALE-Bench contest whose EvoX seed program fails a public case under the judge's time limit (`evox-ahc027`; the same seed passes in a second run, so the limit is tight), the SCiEL MLIR example whose pinned module no longer compiles with Homebrew LLVM 21, and two SCiEL prompt-optimisation examples whose upstream code loads script-based Hugging Face datasets that the current `datasets` package refuses (HotpotQA, HoVer).

## 2. Verified reimplementations

`tests/test_suite.py` executes the pinned AlphaEvolve notebook's data cells and checks the suite's reimplemented verifiers against the published values; all 18 match to machine precision (circle packings 2.6358627564136983 / 2.937944526205518 / 2.3658321334167627, Heilbronn triangle 0.036529889880030156, Heilbronn convex 0.030936889034895648 / 0.02783557145848214, distance ratios 12.88926611203463 / 4.1658497672256525, kissing number 593, hexagon packings 3.930092 / 3.9419123, C1 1.5052939684401607, C2 0.8962799441554086, C3 1.4556427953745406, signed C3 1.4687620697410226, C4 0.35209910442252773 and 0.3215872333529007, C5 0.38092303510845016, C6 1.1479888965092757). The 15 literal matrix-multiplication decompositions published in the AlphaEvolve notebook, including the complex 4×4 rank-48 one, pass the exact integer checker ([recheck](../validation/published-tensor-recheck.json)). The Santa 2025 metric reimplementation reproduces the official metric's doctest value (0.877038143325303) and the getting-started sample submission's score (176.60550959158516) exactly, and rejects the same overlaps ([cross-check](../validation/santa-2025-crosscheck.json)).

## 3. Preflight and seed campaign

`run.py preflight` over the current tree (959 tasks including the expansion in progress) reports 667 tasks ready and 292 blocked (270 unsupported, 20 waiting for data files of the expansion, 1 waiting for `HF_TOKEN`, 1 external service) with the OpenRouter key exported and run-time downloads allowed. The earlier seed campaign through SCiEL's own `Evaluator` over the pinned upstream adapters (309 executed, 160 with an explicit validity signal; [before](../validation/audit-2026-09-19-before.json), [after](../validation/audit-2026-09-19-after.json)) remains available through `run.py evaluate <id> --route upstream`; the suite evaluators supersede it for the question "does the evaluator run".

## 4. Runs with a real model (OpenRouter, Gemini 2.5 Flash)

These are wiring checks under a dollar ceiling, not benchmark results.

- **Live smoke over the whole catalog** (`run.py live-smoke --all`, one SCiEL iteration per usable seed, ceiling $1.00): 177 model requests, verified cost **$0.32**; 69 changed programs evaluated with validity, 86 scored without a validity signal, 22 failed, 939 blocked at that snapshot (`runs/sciel-live-20260919/`).
- **Budgeted experiments** (`run.py experiment`): 2 iterations on `alphaevolve-circle-packing-in-unit-square` (both mutations rejected as overlapping circles, $0.0021), 1 iteration on `reference-circle-packing-26` from the dashboard ($0.0010; that task is now merged into `alphaevolve-circle-packing-in-unit-square`), and 2 iterations on `eoh-online-bin-packing` through its recreated evaluator (two valid mutations, no improvement, $0.0024). None improved on its seed; all confirm the controller, the budget proxy and the evaluators are wired correctly.
- **Model-driven evaluations** in section 1 cost $0.45 in total (482 requests, 86k prompt and 171k completion tokens); responses are cached so re-running the test is free.

No experiment in this repository reproduces a paper's reported result; the seeds are weak baselines and the iteration counts are tiny.

## 5. Repository checks

- `python3 -m unittest discover -s tests`: 222 tests pass (18 optional skips), including invalid-candidate tests, tensor exactness, subprocess isolation, archive safety, budget-proxy accounting with a fake provider, and the suite structure and published-value tests.
- `python3 run.py validate` and `python3 scripts/check_schema.py`: all manifests (903, plus the expansion's) conform to `schemas/task.schema.json` (including the `labels` and `merged_from` blocks) and are consistent with the catalog; `python3 scripts/task_labels.py --check` confirms every task is labelled.

## 7. Labels

`docs/LABELS.md` classifies the 903 tasks by what an improved score would mean: 143 open mathematical problems (all executable here, 78 with an exact published value), 13 discovery tasks on real measurements (10 executable: the eight SLDBench scaling laws, the stress-strain regression and the Pantheon+ supernova fit), 21 rediscovery tasks, 264 method tasks (228 executable), 249 engineering tasks (92 executable) and 213 model benchmarks (139 executable). By coarse `area` the largest groups are language and agents, optimization, mathematics and machine learning.

## 6. What remains unsupported (428)

By reason (after merging): GPU or accelerator hardware 81, simulators that do not run on this machine 66 (Isaac Gym, ManiSkill2, AirSim and RL pipelines with pinned commands only), model-driven benchmarks without a public source 59, LLM agents in environments 46, undistributed datasets 90, external toolchains 34 (MATLAB Stateflow, CSPLib, LLVM/XLA, Frontier-CS judge), special hardware 22 (Trainium, robots), proprietary systems 12. Unsupported means the problem is catalogued (manifest, README, requirements, the paper's protocol and, for 116 of them, the paper's pinned code and commands) but its evaluator cannot run in this suite; the stub evaluator returns `unsupported: true` instead of a score. `docs/NEXT_STEPS.md` lists what would unblock each group.
