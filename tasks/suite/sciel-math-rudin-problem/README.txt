# SCiEL: Degree-ten spherical harmonic L4/L2 ratio

**Paper:** SCiEL — Scientific Closed-loop Evolutionary Learning: benchmark examples (https://github.com/luciferkonn/SCiEL)\
**Task id:** `sciel-math-rudin-problem`\
**Protocol:** `original`\
**Direction:** maximize\

## Task

Choose 21 real degree-ten spherical harmonic coefficients minimizing the L4/L2 ratio approximated by 70×130 spherical quadrature.

Benchmark named in the paper: SCiEL source example rudin_problem. Paper metric: combined_score.
