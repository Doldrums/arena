## Task

construct() -> three lists of paths (vertex lists), one per fixed instance graph generated by instance_graph(n, p, seed) for (20,0.3,1), (25,0.3,2), (30,0.25,3) in the verifier. Paths must be simple, use graph edges, be edge-disjoint and cover all edges. Minimize the total number of paths; Gallai's conjecture predicts at most 10+13+15 = 38. The score is the total number of paths over three fixed random connected graphs; staying within 38 is consistent with the conjecture, exceeding it is not evidence against it.
