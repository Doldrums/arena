# Release contract examples

Both JSON files are nonfunctional examples for the
[private release contract](../../docs/private-releases.md). `example-system`, the
prerelease version, `.invalid` hosts and zero hashes do not register or identify
an existing implementation.

`public-reference.example.json` is the only shape intended for a public PR.
`private-binding.example.json` illustrates worker-only data; real bindings belong
outside the repository and every public publication directory. Do not add
credentials to either format.
